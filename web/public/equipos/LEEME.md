# Fotos propias de los equipos

Este directorio está **vacío en el repositorio a propósito**, y este archivo es
la única excepción del `.gitignore`.

Las fotos de producto de MikroTik, Ubiquiti, TP-Link y Cambium tienen derechos
de autor, y este repositorio es público
(`github.com/programadores-obreros/dudepanel`). Subirlas acá las
**redistribuye**, que es distinto de usarlas — y el historial de git no se
borra: se reescribe.

Las fotos viven en el servidor y en el respaldo del servidor. Nunca acá.

**Cómo se nombran, qué formatos entran, de dónde se pueden sacar
legítimamente y cómo llegan al contenedor: `docs/IMAGENES.md`.**
